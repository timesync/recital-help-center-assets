# Recital Help Center — Cover Assets

Generated cover images (1600×640, 5:2) for every page of the Recital Help Center in Notion.

**This repo must stay public while in use**: the Notion page covers reference these
images via raw.githubusercontent.com URLs, which only resolve publicly. If the repo
goes private, every cover breaks.

**Before going private / migrating hosts**: re-host `covers/*` to the final public
site host, update each Notion page cover to the new URL, then this repo can be made
private or archived.

Generated 2026-10-26 by Alex via flux2-klein, using the official Recital brand
palette (Navy #232463, Yellow #F0B23A, Blue #2A7DF1, Beige #F8F7F1, LightBlue
#D3E5FB, Teal #C2E6DA, Green #DCF166).
